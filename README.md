# System-Monitor-Telegram-Bot
# 🤖 System Monitor Telegram Bot

> 🖥️ **Умный Telegram-бот для мониторинга компьютера в реальном времени!**

Этот проект позволяет прямо из **Telegram** следить за состоянием компьютера: процессором, оперативной памятью, диском, батареей и запущенными процессами. 🚀

---

## ✨ Возможности

🖥️ **Системная информация**

* ⚡ Загрузка CPU
* 💾 Использование RAM
* 💿 Использование диска
* 🔋 Уровень заряда батареи

💾 **RAM**

* 📊 Общий объём памяти
* 📈 Используемая память
* 🟢 Свободная память
* 📉 Процент загрузки

⚠️ **Контроль перегрузки**

* Проверка CPU
* Проверка RAM
* Предупреждение при нагрузке **80% и выше**

⏱️ **Uptime**

* Дни
* Часы
* Минуты
* Правильное склонение слова «день»

🔥 **TOP-5 процессов**

* Пять процессов с самой высокой загрузкой CPU
* PID каждого процесса
* Процент использования CPU

🎛️ **Inline-клавиатура**

* 🖥 Система
* 💾 RAM
* ⚡ Перегрузка
* ⏱ Аптайм
* 🔥 TOP-5 CPU

🔐 **Защита доступа**

* Бот доступен только указанному Telegram ID.

## 📦 Установка

### 1️⃣ Установи Python

Проверь установку:

```bash
python --version
```

### 2️⃣ Установи библиотеки

```bash
pip install pyTelegramBotAPI psutil
```

### 3️⃣ Создай `config.py`

```python
TOKEN = "YOUR_BOT_TOKEN"
```

⚠️ **Не публикуй настоящий Telegram Bot Token на GitHub.**

### 4️⃣ Укажи свой Telegram ID

В `main.py`:

```python
MY_ID = 123456789
```

---

## ▶️ Запуск

Запусти:

```bash
python main.py
```

Если всё настроено правильно, в консоли появится:

```text
🤖 Бот запущен...
```

После этого открой своего бота в Telegram и отправь:

```text
/start
```

---

## 🎮 Управление

После команды `/start` появляется меню:

```text

💾 RAM

⚡ Перегрузка
⏱ Аптайм

```

Также доступны команды:

```text

/uptime
/top
```
